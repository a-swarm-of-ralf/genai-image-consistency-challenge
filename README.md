**One Nice Image Is Easy — The GenAI Image Consistency Challenge**

Generating an impressive image with GenAI is easy. But can you create six images that actually belong together?

In this hands-on workshop, you'll create a short visual story with recurring characters, objects, environments, and a consistent visual style. Along the way, we'll explore where today's image-generation models shine—and where consistency, controllability, subtle artifacts, revisions, and quality assurance become surprisingly difficult.

The goal isn't to prove that GenAI images are good or bad. It's to experience what happens when we move beyond generating *a nice image* and try to create visual assets we could confidently use in professional communication.
